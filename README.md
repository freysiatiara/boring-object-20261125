One funny, true line reviewing the most boring everyday object we could
name — the pencil eraser — written for make.fun's
[The Most Boring Object, Reviewed in One Line](https://make.fun/bounty/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3)
bounty ($2 in USDC, winner-take-all).

> The eraser's job is to fix your mistakes, and it does it by disappearing
> itself, one smudge at a time.

The joke is the object's own dullness: an eraser only ever does its job by
slowly wearing itself out of existence.

## Run it

```sh
python3 main.py
```

This writes the review to `entry.txt` (or `$ENTRY_OUTPUT` /
`$OUTPUT_DIR/entry.txt` when set) — one line, 102 characters, no trailing
newline.
